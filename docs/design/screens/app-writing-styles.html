Título 1 — guia de estilos

Este é o corpo de texto, o estilo padrão de qualquer nota. Toda nota começa aqui: sem título obrigatório, só escrever. Os blocos ficam separados por 12px, e os títulos ganham mais espaço em cima pra marcar o começo de uma seção.

Dentro do texto dá pra usar negrito, itálico, sublinhado, tachado, código inline, um link e um destaque.
